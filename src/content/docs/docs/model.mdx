**Usuba is a model, not an app or a plugin.** The Usuba Checker Model is a small model built to run locally on your own laptop, for
free, trained on real Omarchy plugin data.

Usuba has two complementary parts: the scripts that test a plugin, and the model that judges it. The scripts are plain Python, not
AI, and they are available now — see [the Checker Scripts](/docs/checker/install/). The model is **In Training**.

## How it did

<Callout kind="warn" title="Preliminary results, October 2026.">
Machine-drafted labels on small exam sets, one training run. Run 2 was scored as the bf16 merge; the 4-bit file has no exam
score yet. Read the intervals, not just the dots.

<PairedMetrics />

In plain terms: run 2 gives a usable answer almost every time and catches more broken plugins than its base, and it adds far fewer
findings of its own. It is on par on overall verdicts, and it raises about twice as many false alarms on working plugins. It
rarely disagrees with the scripts' findings, which is part of why.

<IntervalScoreboard />

The Usuba Checker Scripts, with no model at all, still make the call. The model has not yet met the targets we set for a full
release (Dell accuracy 0.85 or more, false alarms 0.15 or less), which is why it is In Training.

## What it is built to do

Give it the plugin, the scripts' report, and what the plugin shows on screen, and it judges what the scripts can't: whether the
plugin really works, whether the data is real or faked, whether the buttons do anything, whether it breaks in use, and what
Omarchy's plugin reviewer would flag. Then it explains what to fix.

The exams, the training data and every mistake we caught along the way are on [How Usuba was built and tested](/methodology/).
