## How to help

1. **Report a plugin the Checker Scripts get wrong.** A mismatch against real Omarchy hardware is the most useful bug report we
   get.
2. **Propose a rule.** The standard is the Checker Scripts' contract; new rules need a reason, a failing example and a fix.
3. **Sweep plugins.** The Usuba Checker Model is trained on Omarchy plugins verified with the Checker Scripts.

## Style

Plain and honest. Say what it does, what is done and what is not. Status is always visible. Numbers carry their context:
what was tested, out of how many, and whether the result is preliminary.
