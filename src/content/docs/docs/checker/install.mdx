The Usuba Checker Scripts are plain Python: standard library only, no AI, no account. The source is public under the MIT
licence at [outboundsync/usuba-checker-scripts](https://github.com/outboundsync/usuba-checker-scripts).

## Requirements

- **Python 3.10 or newer.** Nothing else for the static checks, on any machine.
- **For the runtime stage**, which boots the real Omarchy shell and loads the plugin: the reference Linux x86_64 build, with
  Quickshell and Qt 6.11.3 under `/opt` (built by `functest/dell_env/setup.py`), plus `sway`, `bwrap` and `grim` on your `PATH`.
  Without it, the scripts judge the plugin on the static checks and say so.

## Get the Checker Scripts

```bash
git clone https://github.com/outboundsync/usuba-checker-scripts
cd usuba-checker-scripts
```

There are no release tags yet, so if you need a fixed version, check out a commit. `c20a5d6` is the first one where the static
checks run on any machine.

## Check it works

Run it on one of the reference plugins that ship with the repo:

```bash
python3 functest/functest.py dell-ref/omarchy-4.0.4/shell/plugins/clipboard --reasons
```

The first line is the verdict. On a machine without the runtime build it reads
`PASS (static checks only: runtime skipped, <why>)`.

## From Python

The same checks install as a package, pinned to a commit:

```bash
pip install "usuba-checker @ git+https://github.com/outboundsync/usuba-checker-scripts@c20a5d6e3b573d850a2b414357dcfc389b57684f"
```

`usuba_checker.check_files({path: text})` runs the static checks on a dict of files. The Omarchy reference tree is not in the
package, so outside a clone set `FT_OMARCHY` to a copy of `dell-ref/omarchy-4.0.4`.

<Callout kind="tip" title="Tip">
The scripts are the same on every machine: the same plugin gets the same static verdict on a Mac, a laptop or a CI runner.
</Callout>
